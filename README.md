# Primitive Tribe

A browser-based incremental idle game.

## Run locally

No dependencies or build step are required. Open `dist/index.html` in a browser, or serve it over HTTP:

```sh
python3 -m http.server 8000 --directory dist
```

Then visit http://localhost:8000.

## Source

`dist/index.html` contains the HTML, CSS, and JavaScript source. `.openai/hosting.json` contains the existing ChatGPT Sites deployment configuration.
